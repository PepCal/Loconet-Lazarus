TClientLocoNet

Componente base de comunicación con el servidor LocoNet (TCP).

Propiedades

  • Host: Dirección IP del servidor.
  • Port: Puerto (por defecto 1234).
  • TrackPower: Estado de la vía (ON/OFF).

Eventos

  • OnReceive: Línea recibida completa.
  • OnSensor: Evento de sensor.
  • OnSwitch: Evento de desvío.
  • OnLocoSpeed: Cambio de velocidad.
  • OnLocoDir: Cambio de dirección.
  • OnLoco: Estado completo locomotora.
  • OnRailCom: Evento RailCom.

Métodos principales

  • Connect
  • Disconnect
  • SetSwitch(addr, state)
  • SetLocoSpeedByDCC(dcc, speed)
  • SetLocoDirByDCC(dcc, dir)
  • SetLocoFunctionByDCC(dcc, func, state)

TControlLoco

Control de una locomotora individual mediante su dirección DCC.

Propiedades

  • Client: Referencia a TClientLocoNet.
  • DCC: Dirección de locomotora.
  • Speed: Velocidad actual.
  • Direction: 0 = atrás, 1 = adelante.

Eventos

  • OnChange: Cambio de velocidad/dirección.
  • OnFunctionChange: Cambio de una función.
  • OnFunctionsChange: Cambio global de funciones.

Métodos

  • Stop
  • Forward
  • Backward
  • SetFunction(func, state)
  • GetFunction(func)
  • ClearFunctions

TControlMaqueta

Gestión completa del estado de la maqueta.

Propiedades

  • LocoNet: Cliente LocoNet asociado.
  • SwitchDelayMs: Retardo entre órdenes de desvíos.
  • Zonas: Lista de zonas.

Eventos

  • OnSensor
  • OnSwitch
  • OnRailCom

Métodos

  • AddZona(nombre)
  • SetSwitch(addr, state)

Nota: Los desvíos se envían mediante cola interna con temporizador.

Modelo de Maqueta

TElementoMaqueta

  • Representa un elemento del mapa.
  • Tipos: sensor, switch, rail, texto, gráfico.

TZonaMaqueta

  • Contenedor de elementos.
  • FindByAddr(addr)

Ejemplo básico

var
  client: TClientLocoNet;
  loco: TControlLoco;

begin
  client := TClientLocoNet.Create(nil);
  client.Host := '192.168.1.100';
  client.Connect;

  loco := TControlLoco.Create(nil);
  loco.Client := client;
  loco.DCC := 3;

  loco.Speed := 50;
  loco.Direction := 1;
  loco.SetFunction(0, True);
end;
